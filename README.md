# Cyberware (NeoForge 1.21.1)
Surgery Station + 5 implants. Craft them, hold one, right-click the station to install.
Empty-hand click lists implants; Shift + empty-hand click removes all. Each implant costs max health ("humanity").
Press V with the Sandevistan for a speed/haste burst and dash.
Build: put this folder in a ModDevGradle/NeoForge MDK project (needs the Gradle wrapper), run `./gradlew runClient`.

## Visuals (v1.1)
While the Sandevistan is active: fading magenta-to-cyan afterimages, electric sparks, pulsing screen glow,
wider FOV, an OVERCLOCK/RECHARGING bar (bottom right), and a status icon.
